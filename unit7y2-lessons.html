👕 Let's Get Dressed!

Welcome to Get Dressed! 👚 In this unit, we learn about different clothes and how to talk about the clothes we wear.

We will learn useful vocabulary, practise simple sentences, ask and answer questions, and talk about our clothes in English.

🎯 Learning Outcome 1: Name common clothes in English.
🎯 Learning Outcome 2: Use this and these to talk about clothes.
🎯 Learning Outcome 3: Ask and answer simple questions about clothes.
🎯 Learning Outcome 4: Talk about the clothes you have and wear.

03 Grammar

👕

This

Use this for one thing that is near you.

👟👟

These

Use these for more than one thing that is near you.

👕👖

What are these?

Ask about more than one thing using What are these?

04 Grammar Focus

👕
This

We use this when we talk about one thing near us.

One thing:
This is a T-shirt.
👕 This is a T-shirt.
🧥 This is a jacket.
👟👟
These

We use these when we talk about more than one thing near us.

More than one:
These are shoes.
👟👟 These are shoes.
🧦🧦 These are socks.
👖👖 These are trousers.
🩳🩳 These are shorts.
❓
Asking About Clothes

We can ask about clothes using What's this? and What are these?

One:
What's this?

More than one:
What are these?
👕 What's this?
It's a T-shirt.

👟👟 What are these?
They're shoes.

👕 My Clothes
