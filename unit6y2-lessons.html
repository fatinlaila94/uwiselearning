04 • Grammar Focus

✨ There Is & There Are

1️⃣

There is

FOR ONE THING

There is + singular noun
Use "There is" when we talk about one person, place or thing.
Example: There is a sofa in the living room.
Example: There is a kitchen downstairs.
🔢

There are

FOR TWO OR MORE

There are + plural noun
Use "There are" when we talk about two or more people, places or things.
Example: There are two bedrooms upstairs.
Example: There are three windows in the room.
05 • Asking Questions

❓ Is There or Are There?

❓

Ask about things in a house

QUESTIONS & SHORT ANSWERS

Is there...?
Use this for ONE thing.

Is there a kitchen?
Yes, there is.

Are there...?
Use this for TWO or MORE things.

Are there two bedrooms?
Yes, there are.
